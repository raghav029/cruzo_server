# Car Booking Project

## Project Structure

The project is organized into several directories and files, each serving a specific purpose:

### Root Directory
- **CLAUDE.md**: Documentation related to the project.
- **docker-compose.yml**: Configuration for Docker services used in the project.
- **mvnw**: Wrapper script for Maven to ensure the correct version is used.
- **pom.xml**: Maven Project Object Model file that contains configuration information for the project.
- **TECHNICAL_AUDIT.md**: Technical audit documentation.

### Docker Directory
- **docker/**: Contains SQL scripts for database setup and seeding.
  - **demo_booking_flow.sql**: SQL script for demo booking flow.
  - **seed.sql**: SQL script for seeding initial data.

### Source Directory
- **src/**: Contains the main application source code.
  - **main/**: Main application code.
    - **java/**: Java source files.
      - **com/**: Base package for the application.
        - **carbooking/**: Main package for the Car Booking application.
          - **CarBookingApplication.java**: Main application entry point.
          - **common/**: Common utilities and enums.
          - **config/**: Configuration classes for the application.
          - **controller/**: REST controllers for handling requests.
          - **dto/**: Data Transfer Objects for request and response.
          - **entity/**: JPA entity classes representing database tables.
          - **repository/**: Spring Data repositories for database access.
          - **service/**: Business logic services.
  - **resources/**: Contains application resources.
    - **application.yml**: Configuration file for application properties.
    - **db/**: Database migration scripts.
      - **migration/**: Contains SQL migration scripts.

### Test Directory
- **test/**: Contains test source code.
  - **java/**: Java test files.
    - **com/**: Base package for tests.
      - **carbooking/**: Tests for the Car Booking application.
        - **CarBookingApplicationTests.java**: Main test class for the application.

### Target Directory
- **target/**: Compiled classes and resources generated by Maven.

## Repository Structure

The repository is structured to facilitate collaboration and maintainability. Each component is organized logically, making it easier for developers to navigate and understand the codebase. The use of Maven for dependency management and build processes ensures consistency across different environments.

## File Descriptions

- **CLAUDE.md**: Provides an overview of the project and its objectives.
- **docker-compose.yml**: Defines the services, networks, and volumes for Docker.
- **mvnw**: A script to run Maven commands without requiring Maven to be installed globally.
- **pom.xml**: Contains project dependencies, plugins, and build configurations.
- **TECHNICAL_AUDIT.md**: Contains findings from technical audits conducted on the project.
- **SQL files in docker/**: Used for setting up and seeding the database.
- **Java files in src/**: Contains the main application logic, including controllers, services, and repositories.
- **application.yml**: Configuration settings for the application.
- **Test files in test/**: Contains unit and integration tests for the application.
